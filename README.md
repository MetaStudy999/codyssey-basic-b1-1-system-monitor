## Round 01 원칙

1. 공식 Mission/Evaluation/제공 파일을 가장 먼저 확인합니다.
2. ChatGPT가 전체 Reference Complete Path를 먼저 설계합니다.
3. 입문자는 현재 Step에 필요한 용어와 개념만 JIT 방식으로 학습합니다.
4. 각 Step은 `왜 → 무엇 → 용어/개념 → 명령/코드 → 예상 결과 → 의미 → 오류 해결 → 완료 확인` 흐름으로 진행합니다.
5. 환경 변경은 `현재 상태 확인 → 백업 → 변경 → 문법 검사 → 적용 → 검증 → Evidence` 순서를 지킵니다.
6. Round 01에서는 주요 명령을 사용자가 직접 실행하며 이해합니다. 자동화 스크립트는 재현·복구 보조 수단입니다.
7. Secret, Password, API Key, Token, Private Key, 실제 `*.key` 값은 GitHub·채팅·로그·Evidence에 저장하지 않습니다.
8. 실제 실행·검증·필요 Evidence가 끝나기 전에는 CLEAR로 표시하지 않습니다.
9. 현재 차수에 필요하지 않은 보너스/고도화는 뒤로 미룹니다.
10. B1-1이 `✅ CLEAR`가 되기 전에는 B1-2를 시작하지 않습니다.
