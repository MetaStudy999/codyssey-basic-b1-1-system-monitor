# codyssey-basic-b1-1-system-monitor

코디세이 기초 B1-1 **컴퓨터가 알아서 자기 상태를 점검하게 만들기** 미션 저장소입니다.

## 목표

Ubuntu 환경에서 SSH·방화벽·사용자·그룹·ACL을 구성하고, 제공 Agent를 일반 사용자로 실행한 뒤 Bash 기반 `monitor.sh`로 상태를 점검·기록·자동화합니다.

이 저장소는 단순히 코드를 작성하는 데서 끝나지 않고 다음 흐름으로 미션을 수행합니다.

`요구사항 확인 → 구현 → 실행 → 테스트 → 오류·복구 → 증빙 → 평가 대조 → 재현 → 제출 → 보너스`

## 환경 기준

원본 미션의 기준은 **Ubuntu 22.04 또는 동등한 Linux 환경**입니다.

현재 실제 검증에 사용 중인 환경은 다음과 같습니다.

- Ubuntu 24.04.4 LTS
- x86_64
- systemd 255
- OpenSSH Server
- UFW
- cron

> Ubuntu 24.04.4 LTS는 현재 실습 환경이지 원본 미션의 필수 버전으로 고정하지 않습니다. WSL2·OrbStack·Docker 등 환경 차이는 [환경별 차이](./docs/reference/environment-differences.md)에서 관리합니다.

## 학습 구조: `00 + 5 × 3`

`00`은 전체 지도이고, 실제 학습·수행은 `01~15`를 **5개 묶음 × 3단계**로 기억합니다.

1. **준비와 접근 — `01~03`**: 환경 → 저장소 → SSH
2. **시스템 구성 — `04~06`**: 방화벽 → 권한 → Agent
3. **구현과 자동화 — `07~09`**: Monitor → 자동화 → 테스트
4. **검증과 평가 — `10~12`**: 장애 → 증빙 → 평가
5. **완성과 고도화 — `13~15`**: 재현 → 제출 → 보너스

자세한 순서는 [실습 문서 인덱스](./docs/README.md)를 확인합니다.

## 단계 완료 기준

각 단계는 문서를 작성했다는 이유만으로 완료 처리하지 않습니다.

`구현 완료 + 실제 테스트 + 증빙 확보`

세 조건이 모두 충족되어야 `PASS`로 판단합니다. 전체 요구사항 추적은 [요구사항-검증-증빙 대응표](./docs/reference/requirements-evidence-map.md)에서 관리합니다.

- `docs/`: 입문자 실행·학습 안내서
