# 증빙 자료

명령 출력, 종료 코드, 설정 확인 결과와 화면 캡처를 단계별로 보관합니다.

## 규칙

- 파일명에 단계 번호와 작업명을 포함합니다.
- 가능하면 명령·실행 계정·실행 시각·종료 코드를 기록합니다.
- API 키, 비밀번호, 토큰, 개인 IP 등 불필요한 민감정보는 마스킹합니다.
- 키 파일은 값이 아니라 경로·소유권·권한·존재 여부로 증명합니다.
- 실제 시스템 백업과 운영 로그 전체는 커밋하지 않습니다.
- 문서의 예상 출력을 실제 증빙으로 복사하지 않습니다.
- 실제 실행하지 않은 항목은 증빙을 만들지 않습니다.

## PASS와의 관계

```text
구현
+ 실제 테스트
+ 증빙
= PASS
```

증빙 파일만 존재하거나 문서 설명만 존재하는 상태는 `PASS`로 처리하지 않습니다.
