# B1-1 Round 01 — Mission Clear Checklist

> 이 파일은 공통 CLEAR 골격입니다. 실제 미션 수행을 시작할 때 공식 Mission/Evaluation을 읽고 구체 요구사항으로 교체·확장합니다.

## A. Source
- [ ] 공식 Mission PDF 확인
- [ ] Mission Markdown 확인
- [ ] Evaluation 파일 확인(있는 경우)
- [ ] 공식 제공 ZIP/데이터 확인(있는 경우)
- [ ] 필수와 선택 요구사항 분리

## B. Learn
- [ ] 현재 미션에 반드시 필요한 용어 정리
- [ ] 핵심 개념 설명
- [ ] 필요한 개념도 작성
- [ ] 입문자용 쉬운 설명 확인

## C. Environment
- [ ] 사전 요구사항 확인
- [ ] 기준 환경/버전 기록
- [ ] 필요한 환경설정 완료
- [ ] 설정 후 정상 여부 재검증
- [ ] Secret이 Git에 포함되지 않음

## D. Build
- [ ] 모든 필수 요구사항 구현
- [ ] 입문자가 이해할 수 있는 코드/명령 주석 작성
- [ ] 불필요한 선택/고도화 기능으로 범위가 늘어나지 않음

## E. Verify
- [ ] 자동 검증 가능한 항목 PASS
- [ ] 실제 환경 검증이 필요한 항목 확인
- [ ] 정상 경로 확인
- [ ] 주요 오류/예외 경로 확인

## F. Evidence
- [ ] Evaluation 항목별 Evidence 연결
- [ ] Evidence에 Secret/민감정보 없음
- [ ] 제출/평가자가 재확인 가능한 형태

## G. Final CLEAR
- [ ] 공식 요구사항 누락 없음
- [ ] 구현 완료
- [ ] 실행/검증 완료
- [ ] 필요한 Evidence 완료
- [ ] Beginner Guide가 처음부터 끝까지 연결됨
- [ ] **MISSION CLEAR**
