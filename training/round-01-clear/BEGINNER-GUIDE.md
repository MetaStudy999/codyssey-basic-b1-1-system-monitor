# B1-1 Round 01 — Beginner Guide

이 문서는 B1-1을 처음 수행하는 입문자가 처음부터 끝까지 따라가기 위한 중심 가이드입니다.

> 현재 파일은 공통 훈련 골격입니다. 실제 B1-1 수행을 시작할 때 `b1-1-mission.pdf`, `b1-1-mission.md`, `b1-1-evaluation.md`를 기준으로 요구사항과 단계별 명령을 구체화합니다.

## 00. 미션 한눈에 보기
- 구분: **필수 미션 (REQUIRED)**
- 훈련 차수: **R01 CLEAR**
- 목표: 설명을 따라 실제 미션 요구사항을 충족하고 검증 Evidence를 남깁니다.

## 01. 무엇을 만드는가
공식 Mission 원본을 기준으로 작성합니다.

## 02. 최종 결과
공식 Evaluation에서 확인하는 결과와 연결합니다.

## 03. 평가자가 확인하는 것
공식 Evaluation의 항목을 누락 없이 CHECKLIST와 연결합니다.

## 04. 사전 준비
운영체제, 권한, 필요한 도구, 제공 파일을 확인합니다.

## 05. 반드시 알아야 할 용어
각 용어는 **한글명 (English)**, 한 줄 정의, 쉬운 설명, 이번 미션에서의 사용 위치 순서로 설명합니다.

## 06. 핵심 개념
현재 Step을 수행하는 데 필요한 개념만 먼저 설명합니다.

## 07. 전체 개념도
짧은 흐름은 가로형, 길어지는 흐름은 세로형으로 작성하고 그림 아래에 쉬운 설명을 붙입니다.

## 08. 환경 확인
각 명령은 다음 순서로 작성합니다.

1. 왜 실행하는가
2. 주석이 포함된 명령
3. 예상 결과
4. 정상 판정 기준
5. 실패 시 해결 방법

## 09. 환경 설정
환경 변경이 필요한 경우 **현재 상태 확인 → 백업 → 변경 → 문법/설정 검사 → 적용 → 재검증** 순서를 지킵니다.

## 10. 따라하기 Step 1
### 왜 하는가

### 필요한 용어/개념

### 실행할 명령 또는 코드

### 예상 결과

### 결과의 의미

### 오류가 발생하면

### 완료 확인
- [ ] Step 1 완료

## 11. 이후 Step
실제 미션 요구사항을 최소 단위 행동으로 분해해 같은 형식으로 추가합니다.

## 12. 전체 실행
완성된 결과물을 처음부터 끝까지 실행합니다.

## 13. 테스트와 검증
자동화 가능한 검증과 실제 환경에서 확인해야 하는 검증을 구분합니다.

## 14. 자주 발생하는 오류
실제로 발생 가능성이 높은 오류만 원인 → 확인 → 해결 → 재검증 순서로 기록합니다.

## 15. Evidence
공식 평가 항목별로 어떤 결과가 증빙인지 연결합니다. Secret은 기록하지 않거나 반드시 마스킹합니다.

## 16. 예상 질문과 답변
평가자가 확인할 가능성이 높은 핵심 개념과 구현 이유를 자기 말로 설명할 수 있게 정리합니다.

## 17. Mission CLEAR
`CHECKLIST.md`의 모든 필수 항목이 실제 검증과 Evidence를 갖춘 경우에만 CLEAR로 판정합니다.
