## 이 모듈의 목적

보안 원격 접속(Secure Shell, SSH)과 방화벽(Firewall)을 하나의 네트워크 접근 제어 흐름으로 학습합니다. SSH 포트와 Root 로그인 정책을 먼저 안전하게 설정한 뒤, 방화벽에서 필요한 인바운드(Inbound) 포트만 허용합니다.
