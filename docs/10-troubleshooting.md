# 10. 오류 메시지별 트러블슈팅

## 기록 흐름

`증상 → 재현 조건 → 첫 확인 명령 → 원인 가설 → 검증 → 근본 원인 → 조치 → 재검증 → 재발 방지`

## 대상 영역

- SSH
- 방화벽
- 사용자·그룹
- 권한·ACL
- Agent
- `monitor.sh`
- cron
- logrotate

빠른 오류 검색은 [오류 색인](./reference/error-index.md)을 사용합니다.
