# 04. 방화벽과 네트워크 접근 제어

## 목표

방화벽을 활성화하고 TCP `20022`, `15034`만 필요한 범위에서 허용합니다.

## 주요 작업

1. 현재 규칙 백업
2. `20022/tcp`와 `15034/tcp` 허용
3. 불필요한 규칙 검토
4. UFW 활성화
5. 허용·차단 시험

## STOP 조건

- SSH 허용 규칙이 확인되지 않음
- UFW 활성화 후 새 SSH 접속이 실패함

## 완료 조건

- [ ] UFW active
- [ ] `20022/tcp` 허용
- [ ] `15034/tcp` 허용
- [ ] 비허용 포트 차단 확인
