# 11. 수행 내역서와 증빙 작성

## 목표

실제 수행 결과를 보고서와 증빙 파일로 분리하여 기록합니다.

## 역할 구분

- `reports/`: 수행 결과를 설명하는 문서
- `evidence/`: 명령 출력과 화면 캡처 등 원본 근거

## 필수 증빙

- 환경
- SSH·방화벽
- 사용자·그룹·ACL
- Agent Boot·READY·포트
- `monitor.sh` 권한·정상·실패
- 로그·cron·logrotate
- 복구 시험

## 완료 조건

- [ ] 요구사항별 증빙 연결
- [ ] 민감정보 마스킹
- [ ] 증빙 인덱스 작성
