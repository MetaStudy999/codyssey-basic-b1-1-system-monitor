# 오류 메시지 색인

오류 메시지를 빠르게 찾아 [10. 트러블슈팅](../10-troubleshooting.md)으로 연결하기 위한 색인입니다.

## 예정 항목

- `Connection refused`
- `Connection timed out`
- `Permission denied`
- `Address already in use`
- `Command not found`
- `No such file or directory`
- `Operation not permitted`
- `Unit ssh.service not found`
