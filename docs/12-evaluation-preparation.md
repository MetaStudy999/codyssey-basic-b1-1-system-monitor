# 12. 평가 대비 설명 자료

## 주요 설명 주제

- SSH 포트와 Root 로그인 정책
- 방화벽 최소 허용
- 사용자·그룹·ACL 분리
- `pgrep`와 `ps`
- `ss`와 `netstat`
- CPU·메모리·디스크 파싱
- `>`와 `>>`
- cron 환경
- logrotate
- 프로세스는 있으나 포트가 닫힌 경우
- Nginx 관제로 확장하는 방법
