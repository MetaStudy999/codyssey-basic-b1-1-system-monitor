# 01. 실습 환경 준비와 사전 점검

## 목표

Ubuntu 버전, 아키텍처, systemd, SSH, UFW, cron, ACL 도구와 복구 수단을 확인합니다.

## 주요 작업

1. 현재 사용자·경로·호스트·IP 확인
2. Ubuntu·커널·아키텍처 확인
3. 필수 명령과 서비스 확인
4. 초기 상태 저장
5. VM 스냅샷 또는 복구 경로 확보

## STOP 조건

- sudo 권한이 없음
- systemd를 사용할 수 없음
- 복구용 콘솔 또는 백업이 없음

## 완료 조건

- [ ] 사전점검 통과
- [ ] 초기 상태 저장
- [ ] 복구 수단 확보
