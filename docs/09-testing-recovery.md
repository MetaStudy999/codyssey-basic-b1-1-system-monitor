# 09. 정상·장애·복구 테스트

## 목표

정상 상태와 주요 장애를 안전하게 재현하고 종료 코드와 복구 결과를 기록합니다.

## 테스트 범위

- 정상 실행
- 프로세스 중단
- 포트 미리슨
- 방화벽 비활성 경고
- 자원 임계값 경고
- 로그 권한 오류
- 환경변수 누락
- cron·logrotate 오류

## 안전 원칙

- 한 번에 한 장애만 재현
- 과도한 부하 금지
- 디스크를 실제로 가득 채우지 않음
- 시험 후 반드시 원상복구

## 완료 조건

- [ ] 정상 `0`
- [ ] 필수 실패 `1`
- [ ] 복구 후 정상 재확인
