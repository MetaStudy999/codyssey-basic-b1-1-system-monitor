# 03. SSH 보안 설정

## 목표

SSH 포트를 `20022`로 변경하고 Root 원격 로그인을 차단합니다.

## 안전 순서

`기존 세션 유지 → 설정 백업 → 20022 선허용 → 설정 변경 → sshd -t → 서비스 적용 → 새 세션 접속 → 기존 세션 종료`

## STOP 조건

- 백업 파일이 없음
- 복구용 세션이 없음
- `sshd -t`가 실패함
- `20022`가 LISTEN하지 않음

## 완료 조건

- [ ] SSH `20022` LISTEN
- [ ] 일반 사용자 새 세션 접속
- [ ] Root 원격 로그인 차단
- [ ] 복구 절차 확인
